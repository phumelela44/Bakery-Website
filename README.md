# Cape Crumb Bakery Website

A responsive website for Cape Crumb Bakery, built for WEDE5020.

## About
Cape Crumb Bakery is a local bakery in Sea Point, Cape Town. 
This website showcases our products, story, and contact information.

## Pages
- **Home**: Welcome message and featured products
- **About**: Our bakery story
- **Products**: Menu with bread, coffee, and pastries
- **Enquiry**: Contact form for orders
- **Contact**: Location, phone, and opening hours
